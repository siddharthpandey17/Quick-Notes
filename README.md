# Quick Notes 📝

A notes-app starter project. The UI is ready; implement the JavaScript interactions yourself.

## Checklist
- [ ] Create notes with a title and content
- [ ] Edit and delete notes
- [ ] Pin/unpin important notes
- [ ] Search by title or content
- [ ] Sort by newest, oldest or title
- [ ] Persist notes using `localStorage`
- [ ] Handle empty states and mobile layout
- [ ] Bonus: character counter and export note as `.txt`

## Run
Extract the ZIP, open this folder in VS Code and open `index.html` or use Live Server.

## GitHub
Create a repo named `quick-notes`; then run `git add .`, `git commit -m "Build Quick Notes"`, and `git push`.

## Concepts
Arrays, objects, CRUD, DOM manipulation, event delegation, sorting, searching and localStorage.
